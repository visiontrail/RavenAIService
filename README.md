# 日志暂存服务器 | Log Staging Service

[English](README_EN.md) | 中文

## 项目简介

日志暂存服务器是一个基于 Python 实现的 HTTP 服务，用于接收、处理和分发系统日志文件。该服务提供了完整的日志上传、处理、下载和管理功能，特别针对协议栈日志提供了专用的解压缩处理服务。

## 核心功能

### 📤 日志上传
- 支持通过 PUT/POST 方法上传 tar.gz 格式的日志包
- 智能识别日志类型并进行相应处理

### 📋 日志管理
- 直观的 Web 界面显示日志列表
- 支持批量选择和操作（删除、下载）
- 实时显示文件信息（名称、大小、创建时间）
- 智能标签系统（协议栈日志、OAM与天线日志）

### 🔄 协议栈日志处理
- 自动识别包含"stack"关键字的日志包
- 调用专用工具解压私有压缩格式的协议栈日志
- 异步处理，实时显示处理进度
- 生成人类可读的文本格式日志

### 📊 日志详情
- 独立的日志详情页面，支持 URL 分享
- 预留 AI 分析功能接口
- 完整的日志元数据展示

### 🗂️ 自动清理
- 智能存储管理：默认保留1个月的日志
- 空间不足时自动清理：仅保留最近1周的日志
- 磁盘空间阈值：100GB

## 技术特性

- 🐳 **Docker 容器化**：提供完整的 Docker 部署方案
- 🎨 **现代 UI**：简洁美观的 Web 界面
- ⚡ **异步处理**：大文件处理不阻塞用户操作
- 🔧 **快速部署**：提供 deploy.sh、restart.sh、stop.sh 脚本

## 快速开始

### 使用 Docker 部署

```bash
# 构建和启动服务
./deploy.sh

# 重启服务
./restart.sh

# 停止服务
./stop.sh
```

### 手动部署

```bash
# 安装依赖
pip install -r requirements.txt

# 启动服务
python app.py
```

## 系统要求

- Python 3.8+
- Docker（推荐）
- 磁盘空间：至少 100GB 可用空间
- tool_log_decompress 工具（用于协议栈日志解压）

## 配置说明

主要配置项：
- 日志存储路径
- 处理线程数（默认14）
- 自动清理策略
- 服务端口配置

## API 接口

### 上传日志
```http
PUT /upload
POST /upload
Content-Type: multipart/form-data
```

### 下载日志
```http
GET /download/<log_id>
```

### 日志列表
```http
GET /logs
```
