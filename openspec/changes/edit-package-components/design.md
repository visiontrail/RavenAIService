## Context

组件数据存于包 JSON 的 metadata.components，详情页已兼容对象和历史字符串格式。元数据 PATCH 目前只接受描述和标签。

## Goals / Non-Goals

**Goals:** 支持组件名称和可选版本编辑，保留原权限、字段隔离和错误重试体验。

**Non-Goals:** 不修改归档内文件、包版本或组件升级行为。

## Decisions

- 复用 metadata PATCH 与仓库锁，省去独立端点；省略 components 保留原值，空数组清空。
- PATCH 接受对象数组，名称必填、版本可选；去除首尾空白，限制 100 项和每字段 256 字符，拒绝无效类型，避免上传端宽松转换掩盖输入错误。
- 复用元数据编辑 composable；组件按行输入名称和版本，草稿独立于展示数据。历史字符串数据转换为名称行。切换包时清除草稿，过期保存响应不得覆盖另一包。

## Risks / Trade-offs

- 元数据不反映归档内容变化 → 仅更新已有 JSON 元数据，与描述、标签保持一致。
- 保存失败或用户切换详情 → 保留当前包失败草稿，忽略其他包的过期响应。
