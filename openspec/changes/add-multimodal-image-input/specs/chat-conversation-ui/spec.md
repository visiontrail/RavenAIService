## ADDED Requirements

### Requirement: 对话输入区在任意 Agent 下支持粘贴与附加图片

对话输入区（`AIChat.vue`）SHALL 支持用户通过剪贴板粘贴、拖拽以及图片文件选择三种方式添加图片，并在发送前以缩略图列表展示已添加的图片，每张缩略图 SHALL 提供单独删除操作。该图片附件能力 SHALL 对**任意 Agent**（项目专家、日志分析、包检索、设备联动、通用）均可用，且与既有的「日志文件附件」相互独立、可同时存在。

#### Scenario: 粘贴剪贴板图片

- **WHEN** 用户在输入框聚焦时粘贴包含图片的剪贴板内容
- **THEN** 该图片被加入待发送图片附件并以缩略图展示
- **AND** 纯文本粘贴仍按文本插入，不受影响

#### Scenario: 选择或拖拽图片文件

- **WHEN** 用户通过图片按钮选择图片或将图片文件拖入输入区
- **THEN** 该图片被加入待发送图片附件并以缩略图展示

#### Scenario: 项目专家下也可添加图片

- **WHEN** 当前所选 Agent 为项目专家（其日志文件附件按钮被禁用）
- **THEN** 图片粘贴/选择仍然可用，用户可添加图片附件

#### Scenario: 删除已添加的图片

- **WHEN** 用户点击某张缩略图上的删除操作
- **THEN** 该图片从待发送图片附件中移除，其余图片、日志文件附件与文本保留

### Requirement: 图片附件在发送前进行类型、大小与数量校验

前端 SHALL 仅接受白名单图片 MIME 类型（png、jpeg、webp、gif），并对单张大小与数量上限进行校验（与后端 `OCR_MAX_IMAGE_MB` / `OCR_MAX_IMAGES` 一致）；超限的附件 SHALL 被拒绝并向用户给出明确提示，而不静默丢弃。

#### Scenario: 拒绝不支持的文件类型

- **WHEN** 用户尝试添加非白名单类型（如 PDF 或 svg）
- **THEN** 该文件被拒绝并提示不支持的图片类型

#### Scenario: 拒绝超限的图片

- **WHEN** 用户添加的单张图片超过大小上限，或图片数量超过上限
- **THEN** 超限附件被拒绝并提示具体的大小/数量限制

### Requirement: 发送消息时随附图片至对应 Agent 入口

当待发送图片附件非空时，前端 SHALL 在向当前 Agent 对应入口发送本轮消息时携带这些图片（base64，含 media_type）：JSON 入口（`/chat/stream`、项目专家、包检索）在请求体以 `images` 数组携带；multipart 入口（`/log-analysis/stream`）以表单字段 `images`（JSON 字符串）携带。无图片时请求体/表单 SHALL 与既有行为保持一致。

#### Scenario: 携带图片发送

- **WHEN** 用户在含图片附件的情况下发送消息
- **THEN** 对应入口的请求携带 `message` 文本与非空 `images`
- **AND** 发送成功后输入区的文本与图片附件被清空

#### Scenario: 无图片时请求不变

- **WHEN** 用户发送不含图片附件的消息
- **THEN** 请求体/表单不包含图片或 `images` 为空，行为与现有发送一致

### Requirement: 图片识别降级在对话中可见

当某轮携带图片但后端因未配置 OCR 模型或识别失败而降级时，前端 SHALL 向用户展示「图片未被识别」的提示，且对话 SHALL 仍正常给出基于文本的回复。

#### Scenario: 展示识别降级提示

- **WHEN** 后端返回图片识别降级信息（未配置或失败）
- **THEN** 该会话中展示「图片未被识别」提示，且对话仍正常给出文本回复
