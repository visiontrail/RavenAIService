## ADDED Requirements

### Requirement: 主对话输入区支持粘贴与附加图片

主对话输入区（`AIChat.vue`）SHALL 支持用户通过剪贴板粘贴、拖拽以及文件选择三种方式添加图片，并在发送前以缩略图列表展示已添加的图片，每张缩略图 SHALL 提供单独删除操作。

#### Scenario: 粘贴剪贴板图片

- **WHEN** 用户在输入框聚焦时粘贴包含图片的剪贴板内容
- **THEN** 该图片被加入待发送附件并以缩略图展示
- **AND** 纯文本粘贴仍按文本插入，不受影响

#### Scenario: 选择或拖拽图片文件

- **WHEN** 用户通过附件按钮选择图片或将图片文件拖入输入区
- **THEN** 该图片被加入待发送附件并以缩略图展示

#### Scenario: 删除已添加的图片

- **WHEN** 用户点击某张缩略图上的删除操作
- **THEN** 该图片从待发送附件中移除，其余附件与文本保留

### Requirement: 图片附件在发送前进行类型、大小与数量校验

前端 SHALL 仅接受白名单图片 MIME 类型（png、jpeg、webp、gif），并对单张大小、附件总大小与数量上限进行校验；超限的附件 SHALL 被拒绝并向用户给出明确提示，而不静默丢弃。

#### Scenario: 拒绝不支持的文件类型

- **WHEN** 用户尝试添加非白名单类型（如 PDF 或 svg）
- **THEN** 该文件被拒绝并提示不支持的图片类型

#### Scenario: 拒绝超限的图片

- **WHEN** 用户添加的单张图片或附件总量超过上限，或数量超过上限
- **THEN** 超限附件被拒绝并提示具体的大小/数量限制

### Requirement: 发送消息时随附图片至 /chat/stream

当待发送附件中存在图片时，前端 SHALL 在 `POST /chat/stream` 的 JSON 请求体中以 `images` 字段携带这些图片（base64，含 media_type），与 `message` 文本一同发送；无图片时请求体 SHALL 与既有行为保持一致（不含 `images` 或为空）。

#### Scenario: 携带图片发送

- **WHEN** 用户在含图片附件的情况下发送消息
- **THEN** 请求体包含 `message` 文本与非空 `images` 数组
- **AND** 发送成功后输入区的文本与图片附件被清空

#### Scenario: 无图片时请求不变

- **WHEN** 用户发送不含图片附件的消息
- **THEN** 请求体不包含图片或 `images` 为空，行为与现有纯文本发送一致

### Requirement: 图片解析阶段在对话中可见

当某轮携带图片并触发后端图片理解时，前端 SHALL 依据 run 流中的图片理解 trace 事件向用户展示“正在解析图片/已解析/未解析”的状态提示。

#### Scenario: 展示解析进行中

- **WHEN** run 流下发图片理解进行中的 trace 事件
- **THEN** 该会话中展示图片解析进行中的提示

#### Scenario: 展示降级提示

- **WHEN** 后端因未配置多模态模型或解析失败而降级
- **THEN** 该会话中展示“图片未被解析”的提示，且对话仍正常给出文本回复
