# 说明书附图

**发明名称：一种基于分级技能包与分层提示词编排的多智能体服务方法、系统、电子设备及存储介质**

以下各图以 Mermaid 源码形式提供，可直接渲染为矢量附图；正式提交时按 CNIPA 要求导出为黑白线条图。

```mermaid
flowchart TB
    subgraph ADMIN["管理配置面"]
```

## 图 2　两级技能包存储、校验与合并物化流程图

```mermaid
flowchart TB
    UP["上传技能包 zip"] --> C1{"字节数 ≤ 上限？"}
    C1 -->|否| REJ["拒绝入库"]
    C1 -->|是| C2{"条目数／累计解压量 ≤ 上限？"}
    C2 -->|否| REJ
    C2 -->|是| C3{"路径合法？<br/>（无绝对路径／无 .. ／目标归属校验）"}
    C3 -->|否| REJ
    C3 -->|是| C4{"唯一 SKILL.md？<br/>frontmatter 含合法 name？"}
    C4 -->|否| REJ
    C4 -->|是| REG["写入注册表<br/>（agent 级或 project 级 store/）"]

    REG --> RUN["智能体运行触发物化"]
    RUN --> P1["第一遍：遍历智能体级启用技能"]
    P1 --> LNK["清理同名旧目录 → 符号链接<br/>（失败回退递归复制）"]
    LNK --> P2["第二遍：遍历项目级启用技能"]
    P2 --> OVR{"与智能体级同名？"}
    OVR -->|是| COVER["重新物化 → 项目级覆盖"]
    OVR -->|否| ADD["追加物化"]
    COVER --> OUT["工作区 .claude/skills/ 就绪<br/>返回物化清单"]
    ADD --> OUT
    OUT --> MENU["按同一合并顺序生成<br/>名称＋描述菜单（与物化严格一致）"]
```

## 图 4　智能体运行全流程时序图

```mermaid
sequenceDiagram
    participant U as 用户/前端
    participant S as 服务端（工作区编排＋拼接）
    participant PP as 项目提示词模块
    participant SK as 技能管理模块
    participant L as 大语言模型推理引擎
    participant W as 隔离运行工作区

    U->>S: 运行请求（project_code, locale, question）
    S->>W: 创建工作区，写入 task.json
    S->>S: 读取基础层提示词（agent_key × locale）
    S->>S: 拼接运行时上下文段／能力与仓库适配段
    S->>PP: build_project_prompt_addendum(project_code, agent_key)
    PP-->>S: 项目级附加段（专属层＋共享层，可为空）
    S->>SK: materialize_enabled_skills(agent_key, workspace, project_code)
    SK->>W: 两级技能合并物化至 .claude/skills/
    SK-->>S: 物化清单＋名称/描述总览
    S->>S: 拼接技能可用性菜单段＋回复语言指令段
    S->>L: 提交系统提示词＋用户提示词（setting_sources=["project"]）
    loop 推理过程
        L->>W: Skill 工具按需加载相关技能全文
        L->>W: Read/Grep/Bash 核验真实源码与日志
        L-->>S: 事件流（含 skills_loaded 通知）
        S-->>U: SSE 实时推送
    end
    L-->>S: 结构化 JSON 结果（裸文本时按契约包装）
    S-->>U: 返回最终结果
```

## 图 5　默认提示词幂等播种决策流程图

```mermaid
flowchart TB
    T0["触发：项目创建 或 仓库关联状态变化"] --> Q0{"项目已关联代码仓库？"}
    Q0 -->|是| TA["读取代码工作流模板 T"]
    Q0 -->|否| TB["读取无仓库工作流模板 T"]
    TA --> Q1{"目标文件已存在？"}
    TB --> Q1
    Q1 -->|否| W["写入 T 至该项目·受播种智能体专属层"]
    Q1 -->|是| Q2{"overwrite 强制刷新？"}
    Q2 -->|是| W
    Q2 -->|否| Q3{"现有内容 C == T ？"}
    Q3 -->|是| SKIP1["跳过（幂等）"]
    Q3 -->|否| Q4{"C == 另一变体默认值 T' ？"}
    Q4 -->|是| W2["替换为 T<br/>（仓库形态切换自动换轨）"]
    Q4 -->|否| SKIP2["跳过<br/>（管理员已自定义，绝不覆盖）"]
```

## 图 6　推理过程中技能按需加载流程图

```mermaid
flowchart TB
    START["模型收到系统提示词<br/>（仅含技能名称＋描述菜单）"] --> THINK["推理中评估当前子任务"]
    THINK --> REL{"菜单中是否存在<br/>相关技能？"}
    REL -->|否| WORK["直接使用工作区代码/日志作答"]
    REL -->|是| LOAD["调用 Skill 工具<br/>读取该技能全文"]
    LOAD --> FACT{"技能内容涉及<br/>具体代码事实？"}
    FACT -->|是| VERIFY["到 repo/／logs/ 用 Grep/Read 核验"]
    FACT -->|否| APPLY["采纳其方法论/检查清单"]
    VERIFY --> CONFLICT{"与真实代码冲突？"}
    CONFLICT -->|是| CODEWIN["以真实代码为准<br/>丢弃过时细节并可声明不一致"]
    CONFLICT -->|否| APPLY
    CODEWIN --> APPLY
    APPLY --> MORE{"推理中途出现<br/>新的技能需求？"}
    WORK --> MORE
    MORE -->|是| THINK
    MORE -->|否| OUT["按结构化输出契约产出最终 JSON<br/>（技能裸文本要求 → 包装入 answer/summary 字段）"]
```

## 图 7　提示词热更新与并发控制流程图

```mermaid
flowchart TB
    E0["管理员提交更新<br/>（整文件 或 条目级，携带期望校验和）"] --> V1{"YAML 语法合法？"}
    V1 -->|否| R400["返回 400：解析错误"]
    V1 -->|是| V2{"条目级更新时：<br/>条目 id 命中可编辑白名单？"}
    V2 -->|否| R422["返回 422：未知/不可编辑条目"]
    V2 -->|是| V3{"磁盘当前校验和 == 期望校验和？"}
    V3 -->|"否 且 未 force"| R409["返回 409：文件已被他人修改"]
    V3 -->|"是 或 force"| WTMP["写入临时文件"]
    WTMP --> ATOM["原子 replace 覆盖目标文件"]
    ATOM --> INV["失效各智能体提示词内存缓存"]
    INV --> DONE["下一次智能体运行即用新值<br/>（免重启生效）"]
```
